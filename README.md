# repo-sync test repo three

A small sample repository for testing and trying out [repo-sync](https://github.com/TellurionAutomation/repo-sync), a tool that keeps the git repos on lab machines pinned to known tagged versions from a single manifest.

There's nothing to use here. Each commit changes `howdy.txt`, and the tags `v1`, `v2`, `v2.1` and `v2.1.1` give repo-sync known versions to sync to. repo-sync's sample manifest points at this repo, so you can try a sync without setting anything up.
